# CEO IP Agent 系统模块设计

本文定义 CEO IP Agent 系统的整体模块拆解、职责边界与协作关系，作为系统设计、研发实施与后续扩展的基础规范。

---
## II. 系统总体架构

围绕“企业家 IP 自动化生产”目标，系统构建完整闭环：
数据采集 -> 数据处理 -> 语义理解 -> 选题决策 -> 内容生成 -> 发布反馈 -> 持续优化。

系统采用“业务模块 + Agent 编排层”架构：
- 业务模块：负责具体能力实现。
- Agent 编排层（GoClaw）：负责流程调度与自动执行。

云基线（全面迁移到火山引擎）
- 大模型调用：Volcengine Ark（豆包系列模型）。
- 企业知识库：火山引擎知识检索 + RAG 流程。
- 对象存储：Volcengine TOS（承载所有原始文件、媒体资产、衍生产物）。
- 数据库：火山引擎托管数据库服务（关系型 + 分析型场景）。

---
## III. 模块拆解

系统划分为 9 个核心模块：
1. 数据采集模块
2. 数据存储模块
3. NLP 语义分析模块
4. 企业知识库模块
5. 选题引擎模块
6. 脚本生成模块
7. 内容生产模块
8. 舆情风控模块
9. 数据复盘模块

---
## IV. 模块设计

---
### 1. 数据采集模块

职责
从多渠道采集数据，包括热点信息、评论数据、行业情报和企业内部数据。

数据来源
- 社交平台：抖音、小红书、微博、Bilibili、知乎。
- 评论与私信：账号评论与用户互动。
- 行业情报：新闻网站与科技媒体。
- 企业数据：产品资料、战略信息、CEO 日程。
- 人工导入：视频号及私域数据。

核心能力
- 多平台抓取。
- 定时任务。
- 关键词订阅。
- 失败重试与限流控制。

---
### 2. 数据存储模块

职责
按分层区域存储和管理数据，以支撑分析与查询。

分层结构
- Raw Zone：原始数据（JSON/HTML）。
- Clean Zone：清洗后的结构化数据。
- Insight Zone：分析结果数据。
- Content Zone：选题与脚本数据。

火山引擎实现
- 对象文件（原始文本、图片、视频、中间产物）：统一存储到 Volcengine TOS。
- 结构化业务数据（任务、选题、脚本、工作流状态）：统一存储到火山引擎托管关系型数据库。
- 分析/聚合数据（效果统计、趋势汇总）：根据数据规模和时延目标使用火山引擎分析型数据库。
- Go 服务访问遵循 Volcengine Go SDK 规范（凭证管理、地域与 endpoint、客户端复用、重试策略）。

---
### 3. NLP 语义分析模块

职责
对评论和舆情数据进行语义理解与结构化分析。

核心能力
- 情感分析（正向/负向/中立/混合）。
- 评论分类（提问/质疑/建议/攻击等）。
- 话题抽取。
- 关键词提取。
- 风险识别（敏感词、舆情风险）。
- 用户意图识别。
- 高频问题聚合。

模型调用（火山引擎）
- 全部 NLP 能力由 Volcengine Ark 大模型实现（含分类、抽取、总结、风险推理）。
- Prompt 模板按任务类型（情感、意图、风险）进行版本化与集中管理。
- 增加降级策略：主模型不可用时自动切换同厂商备份模型。

输出
为下游选题与风控提供结构化语义标签。

---
### 4. 企业知识库模块

职责
沉淀企业相关知识，作为内容生成与选题判断的基础。

内容组成
- 行业知识（智能家居、AI 家电、大健康等）。
- 产品知识（功能、参数、应用场景）。
- CEO 风格库（历史发言、语言风格）。
- 品牌表达规范（表达标准、禁用词）。
- 行业知识（政策、趋势）。

技术实现（火山引擎）
- 源文档与媒体文件存储在 Volcengine TOS。
- 索引/向量检索依托火山引擎知识检索能力与 RAG 工作流。
- 检索 + 生成链路统一为：查询改写 -> 召回 -> 重排 -> 上下文组装 -> Ark 生成。
- 知识新鲜度策略：增量索引 + 周期性全量重建。

---
### 5. 选题引擎模块（核心模块）

职责
结合热点、舆情洞察和企业知识，生成高质量选题。

输入
- 热点数据。
- 评论洞察。
- 企业知识。
- 行业趋势。

核心逻辑
- 热点到行业相关性映射。
- 用户关注点识别。
- 传播潜力评估。
- 风险评估。
- CEO 表达适配度。

输出
- 选题标题。
- 核心主张。
- 内容角度。
- 风险提示。
- 优先级评分。

---
### 6. 脚本生成模块

职责
基于选题生成标准化短视频脚本。

输出内容
- 视频主题。
- 核心观点。
- 口播文案。
- 时长结构（60s / 90s）。
- 标签。
- 发布备注。

要求
- 贴合 CEO 表达风格。
- 强调行业高度与逻辑深度。
- 避免营销导向表达。
- LLM 生成全量基于 Volcengine Ark，并使用企业知识库提供的知识增强 Prompt。

---
### 7. 内容生产模块（视频生成）

职责
将脚本转化为可发布的视频内容。

子模块
1. 资产匹配：匹配图片、视频与 B-roll。
2. 分镜生成：生成画面结构。
3. 视频生成：剪辑、拼接、AI 生成。
4. 包装处理：字幕、音乐、封面、特效。

输出
- 完整视频文件。
- 资产包。

存储规范（火山引擎）
- 所有成品文件写入 TOS，并遵循统一目录规范，保证可追踪与可复用。

---
### 8. 舆情风控模块

职责
识别内容风险，避免品牌与舆情问题。

核心能力
- 敏感词检测。
- 负面舆情识别。
- 风险分级（低 / 中 / 高 / 严重）。
- 评论区异常监控。
- 脚本内容审查。

输出
- 风险报告。
- 修改建议。
- 拦截/放行决策。

---
### 9. 数据复盘模块

职责
分析发布后效果并优化系统策略。

分析维度
- 播放、点赞、评论、转发、收藏。
- 完播率、涨粉。
- 评论情感。
- 爆款特征。
- 低表现内容根因。

输出
- 周报/日报。
- 爆款模式总结。
- 内容优化建议。

---
## V. Agent 编排层（GoClaw）

定位
GoClaw 是系统编排层，不属于业务模块。

职责
- 调度各模块执行。
- 编排多 Agent 工作流。
- 管理任务状态。
- 控制执行顺序与依赖关系。
- 统一管理火山引擎客户端生命周期（Ark、TOS、数据库服务 SDK 客户端）。

示例流程
爬虫 Agent
-> NLP 分析 Agent
-> 选题 Agent
-> 脚本 Agent
-> 风控 Agent
-> 内容生成 Agent
-> 报告 Agent

---
## VI. 模块关系总结

数据采集 -> 数据存储 -> NLP 分析 -> 选题引擎 -> 脚本生成 -> 内容生产 -> 发布 -> 数据复盘 -> 反馈回流选题。

企业知识库贯穿全流程，舆情风控模块提供端到端保障。

模型调用、知识检索、对象存储与数据库能力全部统一到火山引擎。

全面云化对模块划分的影响
- 模块划分不变，仍保持 9 个业务模块 + GoClaw 编排层。
- 变化点主要在技术实现层：统一云服务后，跨模块的数据接口与能力调用方式更一致。
- 责任边界不变：数据采集、语义分析、知识库、选题、脚本、内容生产、风控、复盘的业务职责不需要重划。
- 新增的只是平台治理关注点：统一鉴权、配额、监控、容灾与成本治理由平台层集中管理，不上升为新业务模块。

- NLP 语义分析模块。
- 企业知识库模块。
- 选题引擎模块。

阶段 2
- 脚本生成模块。
- 舆情风控模块。

阶段 3
- 内容生产模块。
- 数据复盘模块。

---
## VIII. 总结

系统核心能力是：
理解数据 -> 生成洞察 -> 转化为选题 -> 生产内容 -> 基于反馈持续优化。

目标是实现企业家 IP 内容生产的自动化、系统化与可持续优化。

整体技术基线统一在火山引擎上，确保架构一致性、运维简化与成本/权限治理可控。
